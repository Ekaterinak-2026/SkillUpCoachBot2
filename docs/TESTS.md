**Дата:** сентябрь 2026
**Тестировщик:** Екатерина Кравченко
**Среда:** Telegram Desktop + iOS, продакшн-бот [@SkillUpCoachBot](https://t.me/SkillUpCoachBot)

## ✅ Что проверено

### 1. Онбординг

- [x] `/start` для нового пользователя — приветствие приходит, кнопки выбора цели отображаются
- [x] Выбор цели из 4 сегментов — бот сохраняет сегмент в БД
- [x] Динамические клавиатуры навыков — у каждой цели свой набор
- [x] Добавление навыка через кнопку — бот подтверждает «Figma добавлен»
- [x] Добавление второго, третьего навыка — работает, лимит 5 соблюдается
- [x] Настройка часового пояса — 11 вариантов от Калининграда до Камчатки
- [x] Настройка времени уведомлений — «Оставить 9:00 и 20:00» и «Настроить своё»
- [x] Валидация формата времени — некорректный ввод отклоняется

### 2. Ежедневный цикл

- [x] Утренний вопрос — приходит в назначенное время по часовому поясу
- [x] Выбор типа шага — Теория / Практика / Общение / Рефлексия
- [x] План на день — сохраняется в БД со статусом «запланирован»
- [x] Вечерний чекап — приходит в назначенное время
- [x] Отметка «✅ Да, сделал» — серия +1, звезда +1
- [x] Отметка «❌ Нет, не успел» — серия обнуляется
- [x] Отметка «⏳ Перенесу на завтра» — статус меняется
- [x] Догоняющий чекап — если шаг выбран позже вечернего времени

### 3. Мульти-навыки

- [x] До 5 навыков одновременно — работает
- [x] Попытка добавить 6-й — бот предупреждает о лимите
- [x] Дубликат навыка — бот отклоняет с сообщением
- [x] Архивация навыка — статус меняется на `archived`
- [x] Восстановление из архива — статус возвращается на `active`
- [x] Смена активного навыка через `/settings`

### 4. Команды

- [x] `/start` — для нового и для зарегистрированного пользователя

- [x] `/help` — справка со всеми командами

### 5. Планировщик (APScheduler)

- [x] `check_morning` — утренние напоминания в 09:00 (по TZ пользователя)

## 🐛 Найденные и исправленные баги

Во время тестирования найдены и устранены:

| Баг | Причина | Решение |
|---|---|---|
| Дублирование приветствия | Строка `await message.answer(welcome_text)` была дважды | Удалён дубликат |
| `ImportError: skills_keyboard` | Файл `commands.py` ссылался на удалённую функцию | Добавлен алиас |
| `KeyError` в онбординге | `.get()` без проверки | Добавлен fallback |
| `NameError: _db` | Пропала инициализация `_db = None` | Восстановлена |
| Потеря данных после деплоя | SQLite в контейнере, а не на Volume | Подключён Railway Volume |
| Конфликт двух ботов | Railway + GitHub-интеграция одновременно | Отключена интеграция с GitHub |
| `TelegramConflictError` | Два контейнера одновременно | Оставлена только CLI-деплой |
| Дубли и «ложные» напоминания | `check_nudges` срабатывал в 13:00 для всех | Добавлена проверка `days >= 2` |
| Опросник приходил в странное время | Догоняющий чекап запускался в 00:30 | Заменён на мгновенный чекап после 20:00 |

## 🚧 Известные ограничения

Что **не работает** или работает неидеально (осознанные компромиссы MVP):

- ⚠️ **Данные хранятся в SQLite** — для масштабирования нужно перейти на PostgreSQL.
- ⚠️ **Нет автотестов** — тестирование проводилось вручную.
- ⚠️ **Шрифт в картинке календаря** — на Railway кириллица рендерится как квадратики, поэтому календарь — текстовый.
- ⚠️ **Вечерний чекап приходит только для запланированных шагов** — если утром шаг не выбран, чекап не сработает.
- ⚠️ **Один пользователь = один бот** — нет поддержки корпоративных аккаунтов.
